A two-line robot apology: one sentence owning a specific mistake, one naming the lesson and the fix. The robot set the oven to self-clean while the lasagne was still inside, and learned that clean and cook share one door but never one moment.

## Run it

```sh
python3 main.py
```

This writes the two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after a gate self-check that the text is UTF-8, 1 to 400 characters, not only white space, and exactly two lines of one sentence each.
